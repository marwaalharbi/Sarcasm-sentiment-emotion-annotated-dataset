# Sarcasm-sentiment-emotion-annotated-dataset
Overview
iSarcasmEval, the Arabic intended-sarcasm-detection dataset introduced for SemEval-2022 Task 6 (Abu Farha et al.), is extended here with sentiment and emotion annotations added alongside its original sarcasm and dialect label.
